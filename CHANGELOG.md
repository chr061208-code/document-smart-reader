# Changelog

## 0.3.0 - 2026-08-25

- Added a standalone Windows desktop app for users without Codex.
- Added local document selection, indexing, evidence search, and full-text preview.
- Added compact and full evidence prompts for use with any AI assistant.
- Added a public Python API shared by the CLI, Codex skill, and desktop app.
- Added a repeatable PyInstaller build and GitHub Windows release workflow.

## 0.2.0 - 2026-08-25

- Added PDF and DOCX page-aware local indexing.
- Added ranked Chinese/English chunk retrieval.
- Added hash-keyed cache reuse and extraction-quality diagnostics.
- Added Unicode normalization and extraction-control cleanup.
- Added visual-review routing for layout-sensitive evidence.
- Packaged the skill as an installable Codex plugin.
